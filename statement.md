# Problem Statement

Weather information is useful for students and other people when planning their daily activities. However, weather information can be difficult for a beginner to understand when it is presented only as raw data.

The aim of this project is to create a simple Python application that allows a user to select a major Indian city, obtain recent weather information, and calculate a basic next-day temperature prediction.

## Scope

The project covers 10 major Indian cities. It retrieves recent weather data from an online weather service and uses a simple average-based method for prediction.

## Target Users

- Students
- Teachers
- General users interested in a simple weather application

## High-Level Features

- City selection
- Weather data retrieval
- Temperature prediction
- Rain information
- Simple GUI
- Prediction history
- Basic error handling
